The 1K photographic texture assets in this directory are downloaded on the
user's own computer by double clicking GET_REAL_TEXTURES.bat.

All assets come from Poly Haven, are CC0, and may be used commercially.
The assets are NOT included here because this authoring runtime cannot
retrieve the original image files. Bundled procedural placeholders are used
until the download is run.
