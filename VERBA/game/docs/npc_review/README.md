# Verba NPC visual review

These screenshots are **rendered game frames**, not concept art. The pre-existing JPEGs may be older than the current draft anatomy source. They are baseline reference only until `RENDERED_SOURCE.txt` is generated by a successful current-source Godot screenshot workflow.

The render manifest identifies the exact source commit from which the JPEGs were produced. Do not describe an image as evidence for an unrendered later commit. Compare the baker, smith and painter from front/profile and in the world before approving the draft PR.

The body meshes preserve the village's inherited genomes, animated/severable limb nodes and physical care systems. Review apron-to-torso gaps, shoulder silhouette, jaw/neck transitions, limb length and distinct physiques as visual acceptance criteria.
